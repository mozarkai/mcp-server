# Mozark Kiro Power

[Mozark](https://mozark.ai) is a unified testing platform that connects test case management, AI test generation, real-device execution, and device automation — all accessible via MCP.

## What's Included

This power provides 137 tools across seven categories:

- **Test Case Management (TCM)** — Create, search, update, organize test cases, folders, requirements, test plans, test runs, and bugs
- **AI Test Generation** — Generate functional, edge-case, and automation test cases from screenshots and requirement docs
- **Knowledge Base** — Upload PRDs, BRDs, user stories, and screenshots for grounded test generation
- **Real-Device Execution (Optics)** — Run tests step-by-step on real Android/iOS devices with visual verification
- **Device Automation (Appium)** — Automate device interactions, install apps, find elements, capture screenshots
- **Admin Control Panel (ACP)** — Manage organizations, projects, apps, users, roles, and usage
- **Context & Identity** — Switch between projects, apps, and organizations

## Installation

1. In Kiro IDE, open the **Powers** panel
2. Click **Add Custom Power**
3. Enter this GitHub URL: `https://github.com/mozarkai/mcp-server`
4. Click **Install**

Or use the one-click badge:

[![Add to Kiro](https://kiro.dev/images/add-to-kiro.svg)](https://kiro.dev/launch/mcp/add?name=mozark&config=%7B%22url%22%3A%22https%3A%2F%2Fmcp.mozark.ai%2Fmcp%22%7D)

## Getting Started

After installing, sign in with your Mozark credentials. Test the connection:

"Are you connected to Mozark? Show me devices available to me."

## Usage Examples

**Test Case Management:**
- "Generate negative functional test cases for the checkout flow and save them to the Payments folder."
- "Run TR-12 on a free Pixel 7 with screen recording on."
- "List open bugs assigned to me."

**AI Test Generation:**
- "Generate edge-case tests for offline mode."
- "Which existing cases cover guest checkout?"

**Device Automation:**
- "Install my APK on a Pixel 7 and take a screenshot of the home screen."

**Admin:**
- "How much of our device-hours quota have we used this month?"
